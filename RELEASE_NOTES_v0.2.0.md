# Brise v0.2.0 Alpha

Release date: 2026-02-24

## Highlights
- New `calc:` command for arithmetic expressions with operator precedence and parentheses.
- Enhanced `if:` condition support (`==`, `!=`, `>`, `<`, `>=`, `<=`).
- Improved `say:` command to allow quoted or raw text output.
- Added practical demo: `examples/advanced_demo.bri`.

## Compatibility
- Existing commands (`say:`, `set:`, `Include:`, `List:`, `solve:`, `random:`) remain available.

## Quick start
```bash
brise examples/advanced_demo.bri
```
